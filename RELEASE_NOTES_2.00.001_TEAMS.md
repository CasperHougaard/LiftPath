## 🚀 What's New

### ⭐ NEW: Set Intent System

Track the **purpose** of each set for better progress tracking:

**💪 STRENGTH** (≤7 reps)
• Maximal strength focus
• Weight PRs + 1RM PRs
• 180s rest, RPE 8.0-8.5

**🏗️ BUILD** (8-15 reps)
• Muscle building focus
• Weight PRs + Volume PRs
• 90s rest, RPE 7.0-8.0

**🩸 FLUSH** (16+ reps) ⭐ **NEW**
• Volume & pump work
• Weight PRs only
• 45s rest, RPE 7.0-7.5
• Auto-detected in light workouts

**Benefits:** Separate tracking, intent-specific rest timers, accurate PR detection, better progression suggestions

## 🎓 Quick Guide: Set Intents

• **STRENGTH** = Heavy squats, deadlifts, bench (low reps)
• **BUILD** = Muscle building (moderate reps)
• **FLUSH** = Volume/pump work (high reps)

The app auto-detects based on rep ranges, but you can manually set it when logging sets.
